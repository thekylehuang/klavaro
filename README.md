# Klavaro

A macOS keyboard layout for Esperanto's x-system for typing diacritics. Accessible as an input source in the ctrl+space switcher. Makes the `c`, `g`, `h`, `j`, `s`, and `u` keys dead keys that can be marked with diacritics using the `x` key. Also works with uppercase variants.

## Installation

Clone the repository, then copy the Klavaro.bundle folder into `~/Library/Keyboard Layouts` (create the folder if it does not already exist). Log out, log back in, and then go to `System Settings -> Keyboard -> Text Input -> Input Sources -> Edit -> Add -> Esperanto -> Klavaro`.

The layout was made with [Ukelele](https://software.sil.org/ukelele/).
